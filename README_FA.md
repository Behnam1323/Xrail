# Railway Xray — VMess WebSocket TLS

## قابلیت‌ها
- نصب Xray-core داخل Docker image
- ساخت خودکار UUID
- تولید لینک vmess:// در صفحه اصلی
- endpoint سلامت /health

## Deploy
1. فایل‌های این پروژه را در یک GitHub repository قرار دهید.
2. در Railway از New Project → Deploy from GitHub Repo استفاده کنید.
3. مطمئن شوید Build با Dockerfile انجام می‌شود.
4. در بخش Networking گزینه Generate Domain را بزنید.
5. اگر Railway متغیر RAILWAY_PUBLIC_DOMAIN را خودکار تنظیم نکرد، در Variables مقدار PUBLIC_HOST را برابر دامنهٔ ساخته‌شده وارد کنید، بدون https://.
6. بعد از Deploy صفحهٔ دامنه را باز کنید تا لینک نمایش داده شود.

## محدودیت مهم معماری
این پروژه Xray را روی 127.0.0.1:10000 و پنل وب را روی پورت PORT اجرا می‌کند. Railway TLS را معمولاً در لبه خاتمه می‌دهد؛ ولی لینک VMess فقط زمانی کار می‌کند که درخواست‌های WebSocket روی مسیر /ray از ورودی HTTPS عمومی به پورت داخلی Xray هدایت شوند. پیکربندی عادی سرویس وب Railway لزوماً چنین مسیریابی دوگانه‌ای را در یک سرویس فراهم نمی‌کند. بنابراین این پروژه UUID و لینک را می‌سازد، اما اتصال واقعی را تضمین نمی‌کند. اگر /ray به Xray هدایت نشود، از VPS با پورت 443 یا ارائه‌دهنده‌ای با WebSocket reverse proxy استفاده کنید.

## نکات
- UUID در /tmp است و با جایگزینی کانتینر ممکن است تغییر کند.
- برای استفاده واقعی endpoint عمومی حاوی UUID نسازید و پنل را محافظت کنید.
- این نمونه مدیریت کاربر، سهمیه مصرف یا احراز هویت پنل ندارد.
